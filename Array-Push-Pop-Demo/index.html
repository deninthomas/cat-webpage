📖 Code Examples

Push Example:

let array = []; array.push(10); // [10] array.push(20); // [10, 20] array.push(30, 40); // [10, 20, 30, 40]

Pop Example:

let array = [10, 20, 30, 40]; array.pop(); // Removes 40, returns 40 // array is now [10, 20, 30] array.pop(); // Removes 30, returns 30 // array is now [10, 20]

Reverse with For Loop:

let array = [10, 20, 30, 40]; // Forward for (let i = 0; i < array.length; i++) { console.log(array[i]); // 10, 20, 30, 40 } // Backward (Reverse) for (let i = array.length - 1; i >= 0; i--) { console.log(array[i]); // 40, 30, 20, 10 }

✅ Key Concepts

📌 Push:

  • ✓ Adds one or more values to the end of array
  • ✓ Returns the new length of the array
  • ✓ Modifies the original array
  • ✓ Syntax: array.push(value1, value2, ...)

📌 Pop:

  • ✓ Removes and returns the last value
  • ✓ Returns undefined if array is empty
  • ✓ Modifies the original array
  • ✓ Syntax: array.pop()

📌 For Loop (Reverse):

  • ✓ Start from: i = array.length - 1 (last element)
  • ✓ Condition: i >= 0 (until first element)
  • ✓ Decrement: i-- (go backwards)
  • ✓ Access: array[i] (get element)
