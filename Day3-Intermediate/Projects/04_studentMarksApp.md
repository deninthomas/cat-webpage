# Student Marks App Project

## What is This?
A simple app to store and manage student marks.

## What It Does
1. Create a student object
2. Store student information
3. Display student marks

## Concepts Used
- Objects
- Properties
- console.log()

## How It Works
```
Create student object:
- name: "Ali"
- marks: 85
- grade: "A"

Display: Ali has 85 marks and grade A
```
