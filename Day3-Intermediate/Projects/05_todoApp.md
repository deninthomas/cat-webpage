# Todo Array App Project

## What is This?
A simple app to manage a to-do list using arrays.

## What It Does
1. Create array of tasks
2. Add tasks using push()
3. Remove tasks using pop()
4. Display all tasks

## Concepts Used
- Arrays
- push()
- pop()
- Loops

## How It Works
```
Create todo list:
["Buy milk", "Study", "Play"]

Add task: push("Sleep")
["Buy milk", "Study", "Play", "Sleep"]

Remove task: pop()
["Buy milk", "Study", "Play"]
```
