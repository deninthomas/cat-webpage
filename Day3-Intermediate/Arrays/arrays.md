# Understanding Arrays

## What is an Array?
A list of items stored in ONE variable.

## Simple Explanation
Array = A shopping list
One variable holds many items.

## How to Create
```
const list = [item1, item2, item3];
```

## Examples
```
const colors = ["red", "blue", "green"];
const numbers = [1, 2, 3, 4, 5];
const mixed = ["Ali", 25, true];
```

## Access Items
First item is at position 0:
```
const fruits = ["apple", "banana", "orange"];
fruits[0];  // "apple"
fruits[1];  // "banana"
fruits[2];  // "orange"
```

## Important
- Arrays start at 0 (not 1)
- Use [] to access items
- Each item has a position number

## When to Use
- Store multiple items
- Lists, collections
- Groups of related data
