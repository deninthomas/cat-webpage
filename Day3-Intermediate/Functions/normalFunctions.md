# Understanding Normal Functions

## What is a Function?
A function is a reusable block of code that does one job.

## Simple Explanation
Function = A recipe
You write steps once, then use them many times.

## How it Works
```
function functionName() {
  // Code here
}

functionName();  // Call/use the function
```

## Parts
- `function` - keyword to create function
- `functionName` - name of the function
- `()` - parentheses (empty or with parameters)
- `{}` - code inside braces

## Example
```
function sayHello() {
  console.log("Hello!");
}

sayHello();  // Calls the function
sayHello();  // Can use it again!
```

## When to Use
- Repeated code
- Organized code
- Reusable tasks
- Make code cleaner
