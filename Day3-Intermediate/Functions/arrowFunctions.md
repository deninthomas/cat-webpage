# Understanding Arrow Functions

## What is Arrow Function?
A shorter way to write functions using `=>` (arrow).

## Simple Explanation
Arrow function = Shorter function syntax
Modern way to write functions.

## How it Works
```
const functionName = () => {
  // Code here
};

functionName();  // Call/use it
```

## Syntax
- `const` - declare variable
- `=` - assign function
- `() => {}` - arrow function

## vs Normal Function
```
// Normal
function add() {
  return 5 + 3;
}

// Arrow (same thing, shorter)
const add = () => {
  return 5 + 3;
};
```

## When to Use
- Modern code
- Shorter syntax
- Same as normal functions
- Personal preference
