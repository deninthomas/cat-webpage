# Object-Oriented Programming (OOP)

## What is OOP?
**OOP** = A way to organize code using objects and classes.

Think of it like real-world objects:
- A car has properties (color, brand) and actions (drive, stop)
- A person has properties (name, age) and actions (walk, eat)

## 4 Main Pillars of OOP

### 1️⃣ CLASSES & OBJECTS
- **Class** = Blueprint/Template
- **Object** = Real thing made from blueprint

### 2️⃣ ENCAPSULATION
Hide internal details, show only what's needed.

### 3️⃣ INHERITANCE
Get properties and methods from parent.

### 4️⃣ POLYMORPHISM
Same method, different behaviors.

---

## Simple Analogy

```
Class = Cookie Cutter (Template)
Object = Cookie (Made from template)

class Dog {}        // Blueprint
const myDog = new Dog();  // Real dog
```

## Learning Path

1. **Classes & Objects** - Create blueprints and things
2. **Encapsulation** - Hide and show selectively
3. **Inheritance** - Reuse from parent
4. **Polymorphism** - Same name, different actions

---

## Why Use OOP?
✓ Organize code better
✓ Reuse code
✓ Easy to understand
