# JavaScript Learning Path - Complete Structure

## How to Use This Material
- Each topic has a `.md` file (Theory) and `.js` file (Examples)
- Start with the `.md` file to understand the concept
- Then run the `.js` file to see it in action
- All examples are very simple and beginner-friendly

## Learning Tips

1. **Read First** → Always read the `.md` file first
2. **Small Steps** → Each file has only 2-3 examples
3. **Simple Code** → No complex code, very basic
4. **Run Examples** → Copy and run the `.js` files
5. **Experiment** → Change numbers and try different inputs
6. **Practice** → Repeat examples until you understand
