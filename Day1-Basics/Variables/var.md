# Understanding `var`

## What is `var`?
`var` is used to declare variables (containers to store data).

## Simple Explanation
Think of `var` like a box where you can put things inside. You give the box a name and put data in it.

```
Box Name = var myAge
Box Content = 25
```

## Why Use `var`?
- To store information that your program needs
- To remember values and use them later
- To make your code cleaner

## How to Use It
```
var boxName = value;
```

## Important Points
- `var` can be changed later
- `var` can be used again with the same name (re-declared)
- This is considered OLD way now
- Better alternatives: `let` and `const`

## When to Use `var`?
- Mostly for learning
- Old code still uses it
- Avoid in new projects (use `let` or `const` instead)

---
**Note:** Prefer `let` or `const` in modern JavaScript!
