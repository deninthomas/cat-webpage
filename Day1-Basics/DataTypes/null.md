# Understanding `null` Data Type

## What is `null`?
`null` means NOTHING or EMPTY. It's a value that means "no value".

## Simple Explanation
`null` = Intentionally empty
Like an empty box that you left empty on purpose.

## How to Use
```
const something = null;
```

## Why Use `null`?
- To show that a variable is empty on purpose
- To clear a variable
- To indicate "no value"
- In database queries - null means no data

## Important Points
- `null` is written in lowercase
- It's different from `undefined`
- You CHOOSE to set something as `null`
- It means "intentionally empty"

## Example Scenarios
- User has not selected a profile picture: `null`
- Product is out of stock: `null`
- Customer phone number is not provided: `null`

## Comparison
- `null` = Empty by choice (you set it)
- `undefined` = Empty by accident (system didn't set it)
- Both mean "no value" but different reasons

## When to Use
- When you need to empty a variable
- When a value is intentionally not set
- In database when value doesn't exist
