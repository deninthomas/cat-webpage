# Understanding Number Data Type

## What is Number?
Number is DATA that represents quantities. Can be whole numbers or decimals.

## Simple Explanation
Number = Quantity
Think of it like counting items.

## Examples of Numbers
- `42` - whole number
- `3.14` - decimal number
- `0` - zero
- `-5` - negative number
- `-3.5` - negative decimal

## Important Difference
- `123` = Number (can do math)
- `"123"` = String (text, cannot do math)

## Common Operations
- Addition: `5 + 3` → `8`
- Subtraction: `10 - 4` → `6`
- Multiplication: `4 * 5` → `20`
- Division: `20 / 4` → `5`
- Power: `2 ** 3` → `8` (2 to the power 3)

## Important Points
- Numbers can be used for math
- Decimals are also numbers
- Negative numbers are valid
- Zero is a number

## When to Use
- Age, score, quantity
- Price, distance, height
- Any mathematical calculation
- Anything you need to count or measure
