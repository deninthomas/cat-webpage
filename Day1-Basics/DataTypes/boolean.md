# Understanding Boolean Data Type

## What is Boolean?
Boolean is data that can only be TWO values: `true` or `false`.

## Simple Explanation
Boolean = Yes or No
Think of it like a light switch - ON or OFF.

## Examples
- `true` - Yes, correct, on
- `false` - No, incorrect, off

## Common Use Cases
- Is the user logged in? `true` or `false`
- Is the light on? `true` or `false`
- Is the item available? `true` or `false`
- Did the test pass? `true` or `false`

## Comparison Results
When you compare things, you get a boolean:
- `5 > 3` → `true` (Yes, 5 is greater)
- `5 < 3` → `false` (No, 5 is not less)
- `5 == 5` → `true` (Yes, they are equal)
- `5 != 3` → `true` (Yes, they are not equal)

## Important Points
- Only two values: `true` or `false`
- Written in lowercase
- Very useful in decisions (if/else)
- Used for checking conditions

## When to Use
- Check if something is available
- Check if user is logged in
- Check if password is correct
- Any YES/NO question
