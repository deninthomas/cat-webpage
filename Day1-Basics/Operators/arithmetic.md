# Understanding Arithmetic Operators

## What are Arithmetic Operators?
Operators are symbols used to do calculations and operations on numbers.

## List of Arithmetic Operators
| Operator | Name | Example | Result |
|----------|------|---------|--------|
| `+` | Addition | `5 + 3` | `8` |
| `-` | Subtraction | `10 - 4` | `6` |
| `*` | Multiplication | `4 * 5` | `20` |
| `/` | Division | `20 / 4` | `5` |
| `%` | Modulus (Remainder) | `10 % 3` | `1` |
| `**` | Power/Exponent | `2 ** 3` | `8` |

## Simple Explanation
These are just math operations you do in school!

## Addition `+`
```
5 + 3 = 8
10 + 20 = 30
```

## Subtraction `-`
```
10 - 4 = 6
20 - 15 = 5
```

## Multiplication `*`
```
4 * 5 = 20
3 * 7 = 21
```

## Division `/`
```
20 / 4 = 5
15 / 3 = 5
```

## Modulus `%` (Remainder)
```
10 % 3 = 1  (10 divided by 3 gives 1 remainder)
20 % 4 = 0  (20 divided by 4 gives 0 remainder)
7 % 2 = 1   (7 divided by 2 gives 1 remainder)
```

## Power `**`
```
2 ** 3 = 8  (2 to the power 3 = 2 × 2 × 2)
3 ** 2 = 9  (3 to the power 2 = 3 × 3)
```

## When to Use
- Calculate totals
- Calculate discounts
- Calculate averages
- Any math in your program
