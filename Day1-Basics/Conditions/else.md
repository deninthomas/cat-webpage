# Understanding `else` Statement

## What is `else`?
`else` is used with `if`. It runs code when the condition is FALSE.

## Simple Explanation
`else` means: "If the condition is FALSE, THEN do this instead."

## How it Works
```
if (condition) {
  // Do this if condition is TRUE
} else {
  // Do this if condition is FALSE
}
```

## Flow
1. Check the condition
2. If TRUE → run `if` code
3. If FALSE → run `else` code

## Real World Analogy
- If it's raining → Take umbrella
- Else (not raining) → Don't take umbrella

## Examples
- If age >= 18: Print "Adult" else: Print "Not Adult"
- If score >= 50: Print "Pass" else: Print "Fail"
- If door is locked: Print "Locked" else: Print "Open"

## Important Points
- `else` must come after `if`
- `else` is optional
- Only one of `if` or `else` will run
- You cannot have `else` without `if`

## When to Use
- Two opposite choices
- Yes/No decision
- True/False outcome
- Backup option
