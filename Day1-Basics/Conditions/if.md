# Understanding `if` Statement

## What is `if`?
`if` lets your program make DECISIONS based on conditions.

## Simple Explanation
`if` means: "IF this condition is true, THEN do something."

## How it Works
```
if (condition) {
  // Do this if condition is true
}
```

## Flow
1. Check the condition
2. If TRUE → run the code inside
3. If FALSE → skip the code inside

## Examples
- If temperature > 30: Print "It's hot!"
- If age >= 18: Print "You are adult"
- If score >= 50: Print "You passed"

## Important Points
- Condition must be inside ( )
- Code to run must be inside { }
- If condition is false, code is skipped
- Used for making decisions

## Syntax
```javascript
if (condition) {
  // Code here runs if condition is true
}
```

## Real World
Think of a vending machine:
- If you insert money → machine works
- If you don't insert money → machine does nothing

## When to Use
- Check user age
- Check password
- Validate input
- Make simple decisions
