# Age Checker Project

## What is This?
A simple program that checks if a person is an adult based on their age.

## What It Does
1. Takes an age as input
2. Checks if age >= 18
3. Tells if person is adult or not

## Concepts Used
- Variables (`const`, `let`)
- Comparison operators (`>=`)
- `if` and `else` statements
- `console.log()` for output

## How It Works
```
Input: age = 20
Check: Is age >= 18?
Output: You are an adult!

Input: age = 15
Check: Is age >= 18?
Output: You are not an adult!
```

## Simple Logic
- If age >= 18 → Adult
- Else → Not adult (too young)
