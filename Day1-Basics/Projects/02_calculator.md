# Calculator Project

## What is This?
A simple program that does basic math operations: add, subtract, multiply, divide.

## What It Does
1. Takes two numbers
2. Takes an operation (+, -, *, /)
3. Calculates the result
4. Shows the answer

## Concepts Used
- Variables (`const`, `let`)
- Arithmetic operators (+, -, *, /)
- `if` and `else if` statements
- `console.log()` for output

## Operations Supported
- Addition: `+`
- Subtraction: `-`
- Multiplication: `*`
- Division: `/`

## How It Works
```
Input: num1 = 10, num2 = 5, operation = "+"
Calculate: 10 + 5 = 15
Output: 15

Input: num1 = 20, num2 = 4, operation = "*"
Calculate: 20 * 4 = 80
Output: 80
```

## Simple Logic
- If operation is '+' → Add
- Else if operation is '-' → Subtract
- Else if operation is '*' → Multiply
- Else if operation is '/' → Divide
