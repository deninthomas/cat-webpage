# Day 6 - CSS Basics

## Overview

Master the fundamentals of CSS to style your web pages beautifully.

## Topics Covered

### 1. CSS Selectors & Properties
- Element, class, and ID selectors
- Attribute selectors
- Pseudo-classes (:hover, :focus, etc.)
- Text and background properties

### 2. Box Model & Spacing
- Margin, padding, and border
- Understanding the box model
- Spacing between elements

### 3. Flexbox Layouts
- Creating flexible layouts
- Centering content
- Responsive designs

### 4. Effects & Transitions
- Hover effects
- Smooth transitions
- CSS animations
- Transforms

## Files

- `selectorsProperties.md` - CSS selectors and basic properties
- `boxModel.md` - Understanding margins, padding, borders
- `flexbox.md` - Flexbox layout techniques
- `effects.md` - Hover effects, transitions, animations
- `examples.html` - Complete interactive examples page
- `styling-guide.html` - Practical styling guide

## Quick Start

1. Read the markdown files for theory
2. Open `examples.html` in your browser to see interactive demos
3. Try modifying the CSS to experiment
4. Build your own styled pages!

## Key Takeaways

✅ CSS selectors help you target elements  
✅ Box model controls spacing and sizing  
✅ Flexbox makes responsive layouts easy  
✅ Transitions and animations improve UX  
✅ Mobile-first design is important
