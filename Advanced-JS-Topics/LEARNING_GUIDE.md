**What You'll Learn:**
- Select HTML elements with `querySelector()` and `getElementById()`
- Modify element content with `innerHTML` and `textContent`
- Handle user events with `addEventListener()`
- Change styles and classes dynamically

**Theory Files:**

- [innerHTML-textContent.md](Day4-DOM-Manipulation/innerHTML-textContent.md) - Content modification
- [addEventListener.md](Day4-DOM-Manipulation/addEventListener.md) - Event handling

**Practical Projects:**

| Project | Files | Concepts |
