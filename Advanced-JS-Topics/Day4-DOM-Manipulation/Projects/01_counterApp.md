# Counter App

## What You'll Learn
- Increment and decrement values
- Update DOM in real-time
- Change styles dynamically
- Store state in variables

## Features
- Increase button: adds 1
- Decrease button: subtracts 1
- Reset button: sets to 0
- Color changes based on value:
  - Positive: Green
  - Negative: Red
  - Zero: Black

## How It Works
1. Click buttons to change counter
2. Counter value updates on screen
3. Color automatically changes based on value
4. Counter can be reset at any time

## JavaScript Concepts Used
- `addEventListener()`
- `textContent` property
- `style` property
- Function organization
