# Color Changer App

## What You'll Learn
- Handle color input
- Generate random colors
- Store data with localStorage
- Persist user choices

## Features
- Select custom color from color picker
- Click "Change Color" to apply
- Click "Random" for random background color
- Color choice is saved and restored on page reload
- Hex color code display

## How It Works
1. Select a color from the color picker
2. Click "Change Color" to apply it
3. Or click "Random" for surprise colors
4. Your choice is automatically saved
5. When you reload the page, your color is remembered

## JavaScript Concepts Used
- `addEventListener()`
- `localStorage.setItem()` and `getItem()`
- `Math.random()`
- `style` property manipulation
- Color handling

## localStorage
Saves data in the browser that persists between sessions.
