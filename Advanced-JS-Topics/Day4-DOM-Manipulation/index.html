🎯 Day 4 - DOM Manipulation

Learn to interact with HTML elements using JavaScript

📚 What is DOM?

The DOM (Document Object Model) is a representation of your HTML in JavaScript. It allows you to access and modify HTML elements dynamically.

💡 Tip: DOM manipulation is how you create interactive web pages! Every button click, form submission, and animation happens through DOM manipulation.

1️⃣ querySelector() - Selecting Elements

What is it?

Selects the first element that matches a CSS selector.

Try it:

Code Examples:

// By ID const element = document.querySelector('#myId'); // By class const element = document.querySelector('.myClass'); // By tag const element = document.querySelector('div'); // All matching elements const elements = document.querySelectorAll('.item');

2️⃣ innerHTML vs textContent - Modifying Content

Try it:

Click buttons to change me!

Key Difference:

innerHTML: Sets HTML content (renders HTML tags)

textContent: Sets text only (ignores HTML tags - SAFER)

⚠️ Security Warning: Never use innerHTML with user input! Use textContent instead.

3️⃣ addEventListener() - Handling Events

Try it:

Events: Click, Hover, Input, Type, etc.

Common Events:

click - When element is clicked mouseover - When mouse enters element mouseout - When mouse leaves element input - While typing in input keydown - When keyboard key pressed submit - When form is submitted change - When value changes

4️⃣ classList - Managing CSS Classes

Try it:

This text can be highlighted!

Methods:

element.classList.add('class'); // Add class element.classList.remove('class'); // Remove class element.classList.toggle('class'); // Toggle class element.classList.contains('class'); // Check class

5️⃣ style Property - Direct Styling

Try it:

Click a button to change my color!

Code Example:

element.style.color = 'red'; element.style.fontSize = '20px'; element.style.backgroundColor = 'blue'; element.style.display = 'none'; element.style.paddingTop = '10px';
