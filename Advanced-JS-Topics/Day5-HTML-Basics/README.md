# Day 5 - HTML Basics Examples

Here you'll find practical examples of HTML elements used in web development.

## Quick Reference

### Headings
```html
<h1>Main Title</h1>
<h2>Section Title</h2>
<h3>Subsection</h3>
```

### Lists
```html
<ul>
    <li>Unordered item</li>
    <li>Another item</li>
</ul>

<ol>
    <li>First item</li>
    <li>Second item</li>
</ol>
```

### Links
```html
<a href="https://example.com">External link</a>
<a href="page.html">Internal link</a>
<a href="#section-id">Anchor link</a>
```

### Images
```html
<img src="image.jpg" alt="Description" width="300">
```

### Forms
```html
<form>
    <input type="text" placeholder="Name">
    <input type="email" placeholder="Email">
    <textarea placeholder="Message"></textarea>
    <button type="submit">Send</button>
</form>
```

### Table
```html
<table>
    <tr>
        <th>Header 1</th>
        <th>Header 2</th>
    </tr>
    <tr>
        <td>Data 1</td>
        <td>Data 2</td>
    </tr>
</table>
```
