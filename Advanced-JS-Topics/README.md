# Advanced JavaScript Topics

A comprehensive guide covering DOM Manipulation, HTML Basics, CSS Basics, and Async Programming.

## 📚 Contents

### [Day 4 - DOM Manipulation](./Day4-DOM-Manipulation/)
Learn how to interact with HTML elements dynamically using JavaScript.

**Topics:**
- querySelector() & getElementById()
- innerHTML & textContent
- addEventListener()
- classList manipulation
- Practical Projects: Counter App, Color Changer, Form Validation

### [Day 5 - HTML Basics](./Day5-HTML-Basics/)
Master the fundamentals of HTML structure and elements.

**Topics:**
- HTML Document Structure
- Headings, Paragraphs, Lists
- Links, Images, Tables
- Forms & Input Elements
- Practical Project: Personal Portfolio Page

### [Day 6 - CSS Basics](./Day6-CSS-Basics/)
Learn styling techniques to make your web pages beautiful.

**Topics:**
- CSS Selectors & Properties
- Box Model (Margin, Padding, Border)
- Flexbox Layouts
- Hover Effects & Transitions
- Styling Practical Examples

### [Bonus - Async & Promises](./Bonus-Async-Promises/)
Advanced JavaScript concepts for handling asynchronous operations.

**Topics:**
- Promises & async/await
- try/catch Error Handling
- setTimeout & setInterval
- Fetch API Basics
